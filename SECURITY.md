# Security policy

BioGym Arena does not yet contain a runnable application. Please do not post credentials, private datasets, or unpublished research records in public issues or pull requests.

For a security concern involving this repository or a future implementation, use GitHub's **Report a vulnerability** option in the repository's Security tab when available, or contact the maintainer through the contact method listed on the [GitHub profile](https://github.com/Ajey95). Include enough detail to reproduce the issue without exposing secrets publicly.
