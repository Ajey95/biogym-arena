# Contributing to BioGym Arena

BioGym Arena is currently a documentation-first proposal. Corrections to scientific terminology, evaluation design, accessibility, source attribution, and project scope are welcome.

Before opening a pull request:

1. Check for an existing issue covering the same change.
2. Explain the problem and the evidence behind your proposed change.
3. Keep descriptions of planned features distinct from implemented behavior and measured results.
4. Link primary research or official tool documentation when adding a technical claim.
5. Do not include private biological data, service credentials, or unpublished research records.

For a security concern, follow [SECURITY.md](SECURITY.md) instead of posting sensitive details in a public issue.
