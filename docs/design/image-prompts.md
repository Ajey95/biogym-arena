# Visual reference generation prompts

These prompts produced the two original design boards and their pixel-art revisions with the built-in image generation tool. The outputs are conceptual UI mockups and contain no measured BioGym results.

## Board 1: Lab Floor, Episode Replay, TransferArena

```text
Use case: ui-mockup
Asset type: visual design reference for the planned BioGym Arena web frontend, a bioinformatics AI-agent training and evaluation laboratory. Create a polished widescreen design board showing THREE distinct desktop application screens side by side, separated by thin gutters, as a coherent product system. Screen 1: LAB FLOOR, an elegant overhead/isometric scientific laboratory corridor with a luminous moving floor/track carrying an agent capsule past glass rooms for Protein Sequence, Protein Structure, and Epitope Analysis, ending at a visually distinct TransferArena door; room cards show sessions and episode counts without numeric performance claims. Screen 2: EPISODE REPLAY, a serious research workbench with an actual-looking protein ribbon molecular viewer on the left, precise node-and-edge live execution graph in the center, provenance evidence inspector and LabOps/ResearchSense reward panels on the right, scrub-able timeline along the bottom; clear source-state chips LIVE, FIXTURE, SYNTHETIC. Screen 3: TRANSFERARENA / EVALUATION, same product design with an unseen challenge, two side-by-side agent trajectories for baseline and revised configuration, separate LabOps and ResearchSense scorecards, evidence lineage, a visible Download run ZIP control; use neutral placeholders instead of invented percentages. Visual language: premium scientific software, restrained dark navy base #081827, deep teal and cyan for live data, muted violet for TransferArena, amber only for warnings, crisp typography, clear hierarchy, accessible high contrast, subtle glass and light, realistic 3D biological model tied to data. Render as a credible high fidelity product design mockup, straight-on screen capture, not a photograph of devices. Avoid: generic sci-fi HUD, decorative unrelated molecules, fabricated results or metrics, unreadable dense microtext, logos of external companies, people, watermarks. Keep visible text minimal and legible: 'BioGym Arena', 'Lab Floor', 'Episode Replay', 'TransferArena', 'LabOps', 'ResearchSense', 'Provenance', 'Download run ZIP'.
```

## Board 2: Scientific room and Evaluation Hall

The first board was supplied as a style reference.

```text
Use case: ui-mockup
Asset type: complementary BioGym Arena frontend visual reference. Use the attached BioGym Arena mockup solely as a visual style reference: preserve its premium dark navy product shell, cyan live-data accents, muted violet TransferArena accents, thin borders, clean typography, and clear scientific dashboard hierarchy. Create a new widescreen board with TWO distinct desktop screens side by side, straight-on, high-fidelity interface mockup. LEFT SCREEN: a Protein Structure laboratory room detail page. At top, room name, scientific purpose and two integrated skill chips LabOps and ResearchSense. Below, a tidy list of training sessions as cards, each containing a few episode rows with mode chips ToolGym, ChaosGym, EvidenceGym, status, source provenance badges, and an Open episode action. Include a compact room-scoped molecular preview, but do not let decoration obscure sessions. RIGHT SCREEN: Evaluation Hall for a scientifically rigorous baseline-versus-revised-configuration comparison. Top shows comparison conditions: same held-out task set, same tool budget, same scorer, and visible sample-size placeholder 'n pending'. Main area has side-by-side baseline and revised trajectory mini-graphs with synchronized replay control. Below are two separate scorecards headed LabOps and ResearchSense, with metric names Task success, Recovery, Provenance integrity, Supported claims, Abstention, Efficiency and empty or dash placeholders rather than invented numbers. A provenance detail panel displays Source -> Tool result -> Agent claim. Visible Download comparison ZIP button. Use exact legible labels 'BioGym Arena', 'Protein Structure Room', 'Sessions', 'Episodes', 'LabOps', 'ResearchSense', 'Evaluation Hall', 'Baseline', 'Revised configuration', 'Held-out tasks', 'Provenance', 'Download comparison ZIP'. Keep all copy minimal and crisp. No made-up percentages or claims of trained-model improvement; this is a planned product reference, not an actual result. Avoid: people, devices, external logos, unrelated molecules, generic sci-fi HUD, tiny illegible text, watermarks.
```

Side-on orthographic cutaway view, crisp 16-bit pixel art, clearly visible pixel grid, layered game background, tasteful navy/cyan/violet palette, cozy busy garage atmosphere, legible room plaques, small unobtrusive HUD along top with BioGym Arena and current session, no large dashboard cards, no graph, no evaluation charts, no fake scores, no text-heavy UI. ```
